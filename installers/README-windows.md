# Mewgenics Breeding Mod (Windows)

The in-game bridge for the Mewgenics Breeding Overlay: a Mewjector loader and
our mod DLL are placed in the game folder so the overlay can follow the cat you
select.

## Install

1. Unpack the whole zip and keep the folder together.
2. Double-click `install.bat`.
3. Start Mewgenics normally.

Windows needs no launch option and no registry change.

## Uninstall

Double-click `uninstall.bat`. It asks for confirmation first and names the game
folder it is about to clean.
